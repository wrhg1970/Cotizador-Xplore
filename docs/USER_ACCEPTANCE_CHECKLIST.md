# Checklist de aceptación de negocio

Antes de autorizar el lanzamiento, EE debe verificar:

- [ ] Asesor crea solicitud y recibe folio.
- [ ] Cotizador asignado ve la solicitud.
- [ ] Se crean 3 escenarios sin interferencia entre ellos.
- [ ] Los totales se comparan con una hoja Excel aprobada por Finanzas.
- [ ] Se envía a aprobación y el cotizador no puede autoaprobar.
- [ ] El aprobador devuelve una versión y el comentario queda visible.
- [ ] Se aprueba una versión y luego se modifica un importe: envío queda bloqueado.
- [ ] Se genera PDF comercial sin costes/márgenes internos.
- [ ] Se genera XLSX interno solo para usuarios autorizados.
- [ ] Se registra envío con fecha, destinatario y versión.
- [ ] Se acepta una versión enviada; una segunda aceptación incompatible es bloqueada.
- [ ] Usuarios de una oficina no acceden a otra sin permiso.
- [ ] Fallo de API externa no impide cotizar ni pierde datos.
- [ ] Se exportan reportes respetando permisos.
- [ ] Se verifica backup y restauración.
- [ ] Se capacita a usuarios y se asigna responsable de soporte.
